v1.9.0 MIT License 跨平台 零依赖 多后端 GPU 加速

1. 项目背景

whisper.cpp 是 GitHub 用户 ggerganov（GGML 作者）于 2022 年开源的项目， 旨在将 OpenAI 于同年发布的 Whisper 语音识别（ASR, Automatic Speech Recognition）模型 高效地移植到各种平台和设备上。

OpenAI 官方发布的 Whisper 模型基于 PyTorch，体积庞大、依赖繁重，难以部署在边缘设备或嵌入式场景中。 whisper.cpp 基于自研的轻量级张量库 GGML， 以纯 C/C++ 重写了整个推理流程，对 Apple Silicon、x86 CPU、CUDA、Metal、Vulkan、OpenCL、SYCL 等多种硬件做了深度优化。

项目里程碑

  • 2022 年 9 月：项目开源，迅速在 GitHub 获得数万 Star
  • 2023 年：陆续加入 Metal、CUDA、CoreML、Vulkan 等硬件后端
  • 2024–2025 年：持续迭代，发布 v1.7/v1.8/v1.9 多个稳定版本
  • 当前：已成为嵌入式、端侧、跨平台语音识别的事实标准方案

2. 解决什么问题

whisper.cpp 主要解决以下几类核心问题：

📦

依赖臃肿

PyTorch 部署包动辄数百 MB，whisper.cpp 仅需几 MB 即可运行

📱

端侧部署

让 Whisper 模型可以在手机、嵌入式设备、树莓派上离线运行

🚀

推理性能

通过 GGML 的量化与算子融合，提供接近实时的转录速度

🔌

多语言集成

提供 C API 及 Go/Java/JS/Ruby 等绑定，方便集成到各类应用

🔒

隐私合规

完全本地离线推理，语音数据无需上传云端

💰

推理成本

无需 GPU 服务器，使用普通 CPU 即可完成语音转文字

典型应用场景

  • 实时语音转写：会议记录、字幕生成、采访整理
  • 离线语音助手：智能音箱、车机系统、家居设备
  • 辅助工具：为听障人士提供实时字幕
  • 开发者集成：将语音能力嵌入移动 App、桌面软件、游戏中
  • 批处理转录：对历史音频资料进行批量转写

3. 项目框架结构

项目采用"核心集中 + 平台后端可插拔"的设计理念，主要目录结构如下：

4. 核心模块

4.1 核心库模块（src/）

模块职责
whisper.cpp / whisper.h主实现与 C API，封装所有对外接口

openvino/Intel OpenVINO 加速

4.2 GGML 张量库（ggml/）

作为底层计算引擎，提供张量抽象与多种硬件后端：

后端适用场景
ggml-cpu通用 CPU 推理（ARM NEON、AVX、VSX 优化）
ggml-cudaNVIDIA GPU 推理
ggml-metalApple Silicon GPU 推理

ggml-opencl跨平台 GPU（OpenCL）

4.3 应用示例模块（examples/）

  • cli/：命令行转录工具 whisper-cli，最基础的使用方式
  • stream/：实时流式转录，适合直播、麦克风输入
  • server/：HTTP REST 服务器，提供 Web API
  • bench/：性能基准测试工具，量化不同模型/后端速度
  • command/：语音命令识别，自定义离线语音助手
  • quantize/：模型量化工具（Q4_0、Q5_1、Q8_0 等）
  • whisper.wasm/：浏览器端 WebAssembly 版本
  • talk-llama/：与 LLaMA 等大语言模型联动

4.4 多语言绑定（bindings/）

  • JavaScript/TypeScript：Node.js 与浏览器环境
  • Go：服务端集成
  • Java：Android 与桌面应用
  • Ruby：脚本与 Web 服务

5. 运行流程

whisper.cpp 的核心推理流程可以分为 六个阶段，从原始音频到文本输出：

1

音频输入与重采样

读取 WAV/PCM 原始音频，统一重采样到 16 kHz 单声道 float 格式

↓
2

Mel 频谱计算（whisper_pcm_to_mel）

对音频分帧、做短时傅里叶变换（STFT），应用 80 通道 Mel 滤波器组，输出 log-Mel 频谱

↓
3

编码器推理（whisper_encode）

使用 Transformer 编码器将 Mel 频谱编码为高维特征表示

↓
4

解码器自回归生成（whisper_decode）

使用交叉注意力机制逐 token 生成文本，支持多种采样策略（greedy、beam search、temperature sampling）

↓
5

特殊 token 解析

解析语言标记、时间戳、分段标记等特殊 token，定位转录起止时间

↓
6

输出分段文本

通过 whisper_full_get_segment_text() 获取每一段的转录结果

5.1 完整调用示例（伪代码）

// 1. 初始化上下文
struct whisper_context * ctx = whisper_init_from_file("models/ggml-base.en.bin");

// 2. 配置推理参数
struct whisper_full_params wparams = whisper_full_default_params(WHISPER_SAMPLING_GREEDY);
wparams.language = "en";
wparams.translate = false;

// 3. 准备音频（16 kHz, mono, float）
std::vector<float> pcmf32 = read_wav("samples/jfk.wav");

// 4. 执行完整转录（一站式调用）
whisper_full(ctx, wparams, pcmf32.data(), pcmf32.size());

// 5. 遍历输出分段
const int n_segments = whisper_full_n_segments(ctx);
for (int i = 0; i < n_segments; ++i) {
    const char * text = whisper_full_get_segment_text(ctx, i);
    int64_t t0 = whisper_full_get_segment_t0(ctx, i);
    int64_t t1 = whisper_full_get_segment_t1(ctx, i);
    printf("[%lld --> %lld] %s\n", t0, t1, text);
}

// 6. 释放资源
whisper_free(ctx);

5.2 高级流程（可拆解）

对于流式或自定义场景，可分步调用：

// 音频 → Mel 频谱
whisper_pcm_to_mel(ctx, pcm_data, n_samples, n_threads);

// 手动设置 Mel
whisper_set_mel(ctx, mel_data, n_len, n_mel);

// 编码
whisper_encode(ctx, n_threads);

// 解码（多次调用，每次生成一个 token）
whisper_decode(ctx, tokens, n_tokens, n_threads);

// 采样
whisper_sample_token(ctx, ...);

6. 支持的平台

whisper.cpp 是真正的跨平台方案，覆盖从服务器到嵌入式设备的所有场景：

macOS (Intel) macOS (Apple Silicon) iOS Android Linux FreeBSD Windows (MSVC) Windows (MinGW) WebAssembly Raspberry Pi RISC-V POWER (VSX) Docker

6.1 快速开始

# 克隆仓库
git clone https://github.com/ggml-org/whisper.cpp.git
cd whisper.cpp

# 下载 base.en 模型
sh ./models/download-ggml-model.sh base.en

# 构建项目
cmake -B build
cmake --build build -j --config Release

# 转录音频
./build/bin/whisper-cli -f samples/jfk.wav

或者一行命令完成 下载 + 构建 + 测试：

make base.en

7. 设计哲学总结

  • 单一高效实现：核心逻辑集中在 whisper.cpp 一个文件，便于阅读与移植
  • 清晰的 C API：所有功能通过 whisper.h 暴露，不引入 C++ 运行时
  • 零内存分配：推理时无动态内存分配，性能稳定可预测
  • 可插拔后端：CPU/GPU/专用芯片通过 GGML 统一抽象
  • 小体积量化模型：最低仅需 ~75 MB（tiny）即可启动推理
  • 开放生态：官方绑定覆盖主流语言，第三方集成丰富

whisper.cpp 让我们能够在 任何设备、任何场景下， 享受 OpenAI Whisper 强大的多语言语音识别能力， 是当前最值得关注的开源语音识别项目之一。
